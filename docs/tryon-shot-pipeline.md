콘텐츠 캘린더, SNS 자동발행, 모델 10명, 검수 UI, DB — **전부 안 만듦.**

작성일: 2026-09-18

## 0. 핵심: LoRA 학습이 필요 없습니다

앞선 설계안에서 1순위 난제로 잡았던 "캐릭터 일관성"은 **범위를 단순화하면 아예 발생하지 않습니다.**

매번 모델을 새로 생성하니까 얼굴이 흔들리는 것입니다. 그러지 말고:

> **모델 사진을 각도별로 몇 장 확정해서 PNG로 저장해두고, 매번 그 파일에 모자만 갈아끼웁니다.**

얼굴을 건드리지 않으므로 동일 인물성은 100% 보장됩니다. 파일이 같으니까요.
LoRA 학습, 모델 카드 DB, 얼굴 동일성 QA — **전부 불필요해집니다.**

LoRA가 필요해지는 건 나중에 "새 포즈·새 배경이 계속 필요해질 때"뿐입니다. 그때 가서 붙이면 됩니다.

## 1. 만들 것 (전부)

### 자산 — 한 번만 만들고 끝
```
models/
  female_01/
    front.png  side.png  angle_l.png  angle_r.png  half.png
    *_mask.png          ← 모자 올라갈 머리 영역, 한 번만 그려둠
  male_01/
    (동일)
```
- 모델 **2명**(남1·여1)으로 시작. 각 **5컷**. 총 10장.
- 배경은 무지 단색 또는 심플한 스튜디오 톤으로 통일 → 상품 이미지로 바로 쓰기 좋고 합성 난이도도 낮음.
- 머리카락은 짧거나 묶은 스타일로. 긴 생머리는 모자 합성 실패율이 높습니다.
- 마스크는 헤어라인 위쪽만. 얼굴은 절대 마스크에 포함하지 않습니다.

### 파이프라인 — 스크립트 1개
```
python make_tryon.py --hat products/cap_navy/

  1. 모자 사진 배경제거 (rembg)
  2. 베이스컷 3장 선택 (front / angle_l / side)
  3. Qwen-Image-Edit 인페인팅 (베이스컷 + 모자 + 마스크)
  4. 업스케일
  5. 하단에 AI 생성 표기 삽입
  → out/cap_navy/*.png
```
- ComfyUI를 API 모드로 띄워두고 스크립트가 호출. 워크플로우 JSON 1개.
- DB 없음. 폴더 구조가 곧 데이터.
- 자동 실행 없음. 신상 들어올 때 손으로 돌림.
- 검수: 나온 3장 보고 쓸 것 고름. 이상하면 다시 돌림.

**이게 전부입니다.**

## 2. 컬러 조합 코디 콘텐츠

같은 베이스컷을 쓰기 때문에 이건 거의 공짜로 따라옵니다.
배경·포즈·조명이 완전히 고정이라 그리드로 묶었을 때 깔끔하게 떨어집니다.

```
같은 베이스컷 + 같은 모자 + 상의 색만 변경 → 2×2 그리드 1장
"네이비 캡 × 화이트/베이지/블랙/카키"
```

### ⚠️ 여기서 딱 하나 지킬 것
**AI로 바꾸는 건 옷 색만. 모자 색은 절대 AI로 바꾸지 마세요.**

컬러 배리에이션이 있는 모자는 **실제 컬러별 상품 사진을 각각 합성**해야 합니다.
AI로 모자 색을 돌리면 실물과 미묘하게 달라지고, 그건 그대로 색상 오인 → 반품과 부당광고 문제가 됩니다. 옷은 우리가 파는 물건이 아니니 아무래도 괜찮습니다.

## 3. 법적 표기 — 단순 착용샷은 부담이 확 줄어듭니다

두 규제가 있는데, 단순 착용샷은 한쪽만 걸립니다.

| 규제 | 단순 착용샷에 적용? |
|---|---|
| **AI 기본법** (2026-01-22 시행) — AI 생성물 표시 | **적용됨.** 이미지 하단에 표기 필요 |
| **공정위 추천·보증 심사지침** (2026-06-01 시행) — 가상인물 표시 | 적용 가능성 낮음 |

공정위 지침은 **가상인물이 제품을 추천·보증하는 광고**를 규율합니다. 모델이 모자를 쓰고 서 있기만 하고 체험 증언·추천 멘트가 없으면 추천·보증에 해당하지 않을 가능성이 높습니다. (지침이 요구하는 "인물 가까이 계속 노출" 같은 무거운 요건을 피할 수 있습니다.)

다만 경계가 애매하고, 표기 비용이 사실상 0이므로 **이미지 하단 한 줄을 기본값으로 넣어두는 걸 권합니다.**

```
AI 생성 이미지 · 실제 제품과 차이가 있을 수 있습니다
```

이 한 줄이 AI 기본법 표시 의무와 색상·핏 오인에 따른 표시광고법 리스크를 동시에 덮습니다. 생성 스크립트 마지막 단계에 넣으면 끝이라 운영 부담이 없습니다.

**넘지 말아야 할 선 하나:** 모델이 "써보니 좋아요" 같은 체험 증언을 하는 순간 추천·보증 광고가 되어 훨씬 무거운 표시 의무가 붙습니다. 캡션은 제품 소개 톤으로만 쓰면 됩니다.

실제 색상·사이즈는 AI 이미지가 아니라 실촬 상품컷과 실측 수치로 별도 제공하세요.
